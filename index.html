Bab 1

Struktur Data

Struktur data adalah cara menyusun dan mengatur sekumpulan data agar mudah disimpan, dicari, dan digunakan. Contoh sehari-hari: daftar belanjaan, antrean di kantin, dan silsilah keluarga.

A. List (Daftar)

Sekuensial

Kumpulan data yang disusun berurutan. Contoh: daftar siswa, belanjaan, nilai.

Index 0 Buku
Index 1 Pensil
Index 2 Penggaris

B. Queue (Antrean)

Prinsip FIFO

First In, First Out (FIFO): Yang pertama masuk, pertama dilayani. Contoh: Antrean kasir/bank.

MASUK (Rear) KELUAR (Front)
Citra
Budi
Andi

C. Tree (Pohon)

Hierarki

Susunan bertingkat bercabang. Contoh: Silsilah keluarga, organisasi sekolah, struktur folder.

Root (A)
┌───────┴───────┐
Parent (B) Child (C)

Istilah Kunci pada Struktur Tree:

Root Simpul utama paling atas.
Parent Simpul induk yang memiliki anak.
Child Simpul anak yang berada di bawah parent.
Leaf Simpul paling ujung (tidak punya anak).
INGAT UNTUK UJIAN:
  • Daftar belanja atau daftar nama = List.
  • Antrean pelayanan kasir = Queue (berprinsip FIFO).
  • Silsilah keluarga / Organisasi = Tree. Simpul paling atas disebut Root.
Bab 2

Konsep Lembar Kerja (Microsoft Excel)

Microsoft Excel adalah aplikasi pengolah angka untuk memasukkan, mengatur, menghitung, dan menganalisis data (seperti daftar nilai, kehadiran, atau keuangan).

Anatomi Lembar Kerja:

  • Row (Baris) Susunan mendatar (Angka 1, 2, 3...)
  • Column (Kolom) Susunan tegak (Huruf A, B, C...)
  • Cell (Sel) Pertemuan Baris & Kolom (Contoh: A1, B2)
  • Workbook & Worksheet File Excel & Lembar Kerja di dalamnya
Simulasi Formula Excel Selalu diawali '='
A1 = 70 | A2 = 80 | A3 = 90
=SUM(A1:A3) 240 (Menjumlahkan)
=AVERAGE(A1:A3) 80 (Rata-rata)
=COUNT(A1:A3) 3 (Banyak sel berisi angka)
=AND(A1>=70, B1>=75) TRUE/FALSE (Semua syarat harus benar)
INGAT UNTUK UJIAN:

Rumus Excel wajib diawali tanda sama dengan (=). Contoh sel A1 berarti Kolom A dan Baris 1. Fungsi AND bernilai TRUE hanya jika seluruh kondisi yang diperiksa benar.

Bab 3

Berpikir Komputasional (BK)

Berpikir Komputasional adalah cara berpikir logis, sistematis, dan terstruktur untuk memecahkan masalah. Metode ini bisa diterapkan tanpa komputer sekalipun!

1. Dekomposisi

Memecah masalah besar menjadi bagian-bagian kecil yang mudah dikelola.

Ex: Membagi tugas piket
2. Pengenalan Pola

Mencari kesamaan atau pola berulang dari masalah sebelumnya.

Ex: Jadwal upacara tiap Senin
3. Abstraksi

Fokus pada informasi penting dan mengabaikan detail tak relevan.

Ex: Melihat peta jalan utama
4. Algoritma

Menyusun langkah-langkah logis secara terurut untuk solusi.

Ex: Resep masak mi instan

Beda Efektif dan Efisien:

Efektif Tujuan atau hasil berhasil dicapai dengan baik sesuai target.
Efisien Tujuan dicapai dengan lebih hemat waktu, tenaga, atau biaya.
INGAT UNTUK UJIAN:

Dekomposisi = memecah masalah | Pengenalan Pola = mencari kesamaan | Abstraksi = memilih hal penting | Algoritma = urutan langkah.

Bab 4

Mesin Pencari di Internet

Browser (Peramban)

Aplikasi perangkat lunak untuk membuka & menjelajahi halaman web. Contoh: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari.

Search Engine (Mesin Pencari)

Layanan situs web untuk mencari informasi berbasis kata kunci. Contoh: Google Search, Bing, Yahoo, DuckDuckGo.

URL & Address Bar

URL adalah alamat unik web (misal: https://www.google.com). Address bar adalah tempat mengetikkan URL di bagian atas browser.

Bookmark

Fitur penanda untuk menyimpan alamat situs web favorit agar mudah dibuka kembali di kemudian hari.

INGAT UNTUK UJIAN:

Chrome & Firefox = Browser | Google & Bing = Search Engine | URL = Alamat situs | Bookmark = Menyimpan situs favorit.

Bab 5

Kredibilitas Data & Keamanan Digital

4 Langkah Memeriksa Kebenaran Informasi (Anti-Hoaks):

1
Periksa Sumber
Apakah dari situs resmi? (cth: BMKG)
2
Periksa Tanggal
Apakah berita lama diproduksi ulang?
3
Bandingkan
Cek di media tepercaya lainnya.
4
Pastikan Bukti
Jangan langsung klik 'Share'.
Perbedaan Data vs Informasi:
  • • Data: Fakta mentah berupa angka/simbol yang belum diolah (Contoh: nilai 70, 80, 90).
  • • Informasi: Data yang sudah diolah sehingga bermakna (Contoh: nilai rata-rata siswa adalah 80).
Keamanan File .APK:

Jangan sembarangan mengunduh/memasang aplikasi bertipe .apk dari tautan atau pesan tak dikenal. File tersebut dapat mengandung malware atau pencuri data akun!

Bab 6

Sistem Komputer

Sistem komputer adalah gabungan 3 komponen utama yang saling bekerja sama: Hardware (Perangkat Keras), Software (Perangkat Lunak), dan Brainware (Pengguna/Manusia).

Input Device

Memasukkan data ke komputer.

Contoh: Keyboard, Mouse, Scanner, Mikrofon, Webcam.
Process Device

Mengolah data instruksi.

CPU & ALU (Arithmetic Logic Unit) untuk hitungan & logika.
Output Device

Menampilkan hasil olahan data.

Contoh: Monitor, Printer, Speaker, Proyektor.
Storage Device

Menyimpan data file.

RAM (Sementara), SSD/Harddisk, Flashdisk (Eksternal).
INGAT UNTUK UJIAN:

RAM menyimpan data sementara saat program berjalan | CPU memproses data | ALU mengurus logika & aritmatika | Brainware = manusia pengoperasi komputer.

Bab 7

Ruang Publik & Etika Digital

1. Ruang Publik Nyata (Fisik)

Tempat interaksi langsung secara fisik.

Contoh: Taman kota, perpustakaan, lapangan, alun-alun, pasar.

2. Ruang Publik Virtual (Digital)

Tempat interaksi lewat jaringan internet.

Contoh: Grup WhatsApp, forum daring, kolom komentar, media sosial.
Etika Utama Komunikasi Digital:
  • • Gunakan bahasa yang sopan & tidak merendahkan.
  • • Hati-hati menjaga data pribadi diri & orang lain.
  • • Tidak melakukan perundungan (cyberbullying).
  • • Menghormati perbedaan pendapat sesama anggota.

Teknologi Informasi & Jaringan LAN

Folder & Subfolder

Folder adalah wadah tempat menyimpan & mengelompokkan file. Subfolder adalah folder yang berada di dalam folder lain.

📁 INFORMATIKA (Folder Utama)

LAN (Local Area Network)

Jaringan komputer yang menghubungkan perangkat dalam wilayah lokal/terbatas (seperti laboratorium komputer sekolah, kantor, atau rumah) untuk saling bertukar data atau berbagi printer.
